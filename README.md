# Bootcamp Full Stack con Java: ejercicios

Ejercicios y prácticas que hice durante el bootcamp **Desenvolupament Web FullStack amb Java** (576 h, Fundación Esplai, Tarragona, febrero–agosto de 2025), ordenados por módulo.

Es mi cuaderno de aprendizaje: desde el primer "Hola mundo" hasta un CRUD con patrón MVC y páginas web en equipo. Los proyectos más completos tienen su propio repositorio (enlaces al final).

## Contenido

| Carpeta | Módulo | Qué hay |
|---|---|---|
| `0-Iniciales`, `C1-Intro` | Introducción a la programación | Primeros programas en Java |
| `C2JavaBasics` | Programación orientada a objetos | Tipos y flujo de datos, métodos y arrays, ArrayList y Hashtable, herencia, interfaces gráficas con Swing y acceso a bases de datos con **JDBC** |
| `C3BasesDatosSQL` | Bases de datos | DDL, DML (consultas de inserción, modificación y borrado) con **MySQL** e introducción a **MongoDB** |
| `C4`, `C4-MavenTasques` | Backend con Java | Proyectos **Maven** con tests en **JUnit** y un conversor de monedas |
| `UD22_MVC_CrudVideos` | Backend con Java | CRUD de vídeos con el patrón **MVC** |
| `C5Frontend` | Frontend | **HTML5, CSS3, Bootstrap, JavaScript** y una introducción a **React**; incluye una tienda web hecha en grupo |

## Cómo abrir los ejercicios

- Los proyectos Java se abren en Eclipse o IntelliJ. Los que tienen `pom.xml` se compilan con `mvn package`.
- Los ejercicios de JDBC necesitan el conector de MySQL; en los proyectos Maven se descarga solo como dependencia.
- Las páginas web se abren directamente en el navegador.
